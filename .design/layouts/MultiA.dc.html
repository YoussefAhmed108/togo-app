The switcher, not the chip row
The chip row is a shortcut, never the control. Tapping it opens this sheet, which scales to any number of spaces: search, multi-select, and two pseudo-entries for “all pins” and loose saved places. Selection is sticky between sessions.
Rule: the map never shows more than the user asked for. Default on first launch is All pins; after that it remembers.
